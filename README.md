# Traveloop 🌍✈️

Traveloop is an AI-powered smart travel companion designed to make trip planning easier, safer, and more organized. From estimating travel costs to managing important travel essentials like documents, clothing checklists, and journals, Trebloop helps users plan and track their journeys seamlessly in one place.

## Tech Stack 🚀
- **Frontend:** React.js  
- **Authentication:** Firebase Authentication  
- **Database:** MongoDB  
- **Backend & APIs:** Node.js / Express.js  

Traveloop combines AI-driven travel assistance with an intuitive user experience to create a smarter way to explore the world.
